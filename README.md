# Progetti di Elettronica Digitale

Repository contenente i progetti VHDL realizzati con Vivado per il corso di Elettronica Digitale.

## Dettagli sui progetti

### Primo progetto

- Circuito: sommatore a 16 bit.
- Architettura: quattro blocchi CLA a 4 bit collegati come un Ripple Carry.


### Secondo progetto

- Circuito: Mini-Alu a 8 e a 16 bit.


### Terzo progetto

- Circuito: Sommatore a 6 operandi ad 8 bit in complemento a 2.
- Architettura: struttura a pipeline ad albero di sommatori.
